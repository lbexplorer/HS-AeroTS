\subsection{Data Preprocessing and Feature Representation}
\label{sec:data_preprocessing}

UAV-SEAD was used as the primary real-flight dataset \cite{kabaoglu2026uavsead}. The input to this layer is a collection of PX4 ULog files and their anomaly annotations. To make the data inventory reproducible, the dataset revision was fixed to \texttt{\seqsplit{774a336a1d1d06b248927a35c2ea1f6869e9e1a4}}, and the original ULog files were retained as read-only inputs. Inventory and parsing checks excluded one missing file, two parse failures, and four excessive-duration or corrupt logs, leaving 1,389 usable logs. Numeric fields were first restricted to the state-estimation-related topic--field candidates defined in the preprocessing code, and fields with fewer than two finite timestamped samples or no measurable variation were excluded. A channel was then retained when it occurred in at least 60\% of the usable logs, producing a common set of 87 telemetry channels. The output of this step is a flight-indexed set of raw channel sequences and the associated annotation intervals; aligned arrays and feature matrices were generated as derived artifacts by versioned scripts and configuration files.

Because uORB topics are logged asynchronously, each flight was resampled independently onto a uniform 10 Hz grid with a 100,000-$\mu$s step. Let $x_{c,t}$ denote the value of retained channel $c$ at aligned time index $t$. Finite samples within a channel were linearly interpolated by timestamp, values outside the observed interval were extended from the nearest finite endpoint, and a channel absent from an entire log was initialized to zero. Flight boundaries were never crossed during interpolation. This procedure yielded 1,892,063 aligned records across the 1,389 logs. The log identifier and the original annotation intervals were retained alongside every aligned sequence, so window construction and labeling never crossed a log boundary. This does not imply that every evaluation partition contains disjoint source logs: the fixed chronological reproduction can split a log across partitions, whereas leave-log-out assigns entire logs to one partition.

Each aligned flight sequence was converted into overlapping input windows. For window index $w$, $\mathbf{x}_{w,c}$ denotes the $L=96$ aligned samples of channel $c$, and consecutive windows start $s=8$ samples apart. A horizon of $h=12$ additional samples was used only for label assignment and was not included in $\mathbf{x}_{w,c}$. The binary label $y_w^{\mathrm{bin}}$ was set to one if an annotated anomaly occurred anywhere from the window start through the end of this horizon. The window type was selected by the majority nonzero anomaly-type code over the same window-plus-horizon segment; codes 1--4 denote the four explicit fault domains and code 5 denotes Uncategorized. Thus, $y_w^{\mathrm{bin}}$ defines the Stage 1 target, whereas Stage 2 retains only windows whose majority type is one of the four explicit domains. Under the primary chronological protocol, this construction produced 218,537 windows. Split assignment preceded normalization. For channel $c$, the mean $\mu_c^{\mathrm{tr}}$ and standard deviation $\sigma_c^{\mathrm{tr}}$ were estimated only from samples participating in training windows, after which all partitions were transformed as
\begin{equation}
z_{c,t}=\frac{x_{c,t}-\mu_c^{\mathrm{tr}}}{\widetilde{\sigma}_c^{\mathrm{tr}}},\qquad
\widetilde{\sigma}_c^{\mathrm{tr}}=
\begin{cases}
\sigma_c^{\mathrm{tr}}, & \sigma_c^{\mathrm{tr}}\geq 10^{-6},\\
1, & \sigma_c^{\mathrm{tr}}<10^{-6}.
\end{cases}
\label{eq:channel_standardization}
\end{equation}
Here, $c\in\{1,\ldots,87\}$ indexes the retained channels, $t$ indexes the aligned samples, and $\widetilde{\sigma}_c^{\mathrm{tr}}$ prevents division by a near-zero training standard deviation. Within each protocol, this ordering restricts estimation of the feature scale to training-window samples. The fixed 87-channel dictionary, however, was selected using unlabelled coverage across the corpus; it is not a training-only channel-discovery experiment. The fixed chronological, purged, and leave-log-out assignments are detailed in Table~\ref{tab:protocol}.

Following the temporal-statistical representation used by AeroTSBoost \cite{wei2026aerotsboost}, each normalized channel window was summarized by 18 descriptors: mean, standard deviation, minimum, maximum, range, five quantiles (10th, 25th, 50th, 75th, and 90th), start value, end value, endpoint difference, mean and standard deviation of first differences, mean and maximum absolute first difference, and lag-one autocorrelation. Let $d_k(\mathbf{z}_{w,c})$ denote descriptor $k$ applied to the normalized window of channel $c$, where $k\in\{1,\ldots,18\}$. For window $w$, concatenation over the 87 channels gives
\begin{equation}
\mathbf{f}_w=\left[d_k\!\left(\mathbf{z}_{w,c}\right)\right]_{k=1,\ldots,18;\,c=1,\ldots,87}\in\mathbb{R}^{1566}.
\label{eq:window_feature_vector}
\end{equation}
The vector therefore contains $18\times87=1566$ features. If $j$ indexes a coordinate of $\mathbf{f}_w$, the accompanying feature dictionary stores its descriptor index $k$, telemetry channel $c$, and PX4 topic. This explicit provenance is the interface between preprocessing and the explanation layer: it allows each feature contribution to be assigned to a channel and then to a topic and subsystem without reconstructing names from strings.
