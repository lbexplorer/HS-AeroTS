\subsection{SHAP-Based Explainable Evidence}

For each Stage 2 prediction, TreeSHAP contributions for the predicted class raw score were retained and converted to non-negative evidence magnitudes. For feature $j$ and predicted class $\hat{c}(x)$,

\[
e_j(x)=\left|\phi_j^{(\hat{c}(x))}(x)\right|.
\]

The feature dictionary defines the aggregation sets. Channel-, topic-, and subsystem-level evidence is obtained by summing feature evidence through the hierarchy:

\[
E_q(x)=\sum_{j\in\mathcal{F}(q)}e_j(x),\qquad
E_t(x)=\sum_{q\in\mathcal{Q}(t)}E_q(x),\qquad
E_s(x)=\sum_{q\in\mathcal{Q}(s)}E_q(x).
\]

Aggregation conservation is checked at each level using

\[
\epsilon_L(x)=\sum_{u\in L}E_u(x)-\sum_j e_j(x).
\]

Evidence quality is evaluated by validation-derived SHAP top-$k$ masking against equal-size random masking, and by channel-level Consistency@K and Hit@K against a document-derived semantic channel-to-subsystem mapping. The reference mapping is defined from PX4 message topics and field semantics without access to SHAP values. It corrects generic string-token leakage in the original rule, such as attitude yaw and manual-control axes being interpreted as global-position fields; 11 of 87 channel assignments change. Shared channels are treated as non-matches for a specific subsystem. Because the reference is still author-defined rather than independently expert-adjudicated, Consistency@K is reported as mapping sensitivity, not subsystem ground-truth validation.

The primary masking test replaces selected test features with feature-wise medians computed from training windows. A sensitivity analysis instead replaces all selected features in each test window with their joint values from one deterministically sampled training-window donor. The donor preserves dependence within the replaced block, although combining it with unreplaced test features can still be off-manifold. Random feature subsets are nested within each model seed. Paired uncertainty is estimated by resampling complete flight logs and averaging the contrast across the five model seeds. These tests assess numerical organization and prediction sensitivity under specified perturbations; they do not establish physical causality or feature necessity.
