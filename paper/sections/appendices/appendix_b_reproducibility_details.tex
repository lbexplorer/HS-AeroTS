\section{Reproducibility and Statistical Details}
\label{app:reproducibility}

\subsection{Software and Frozen Versions}

The earlier frozen-prediction recomputation (P13) used Python 3.12.13, NumPy 2.3.5, pandas 3.0.1, scikit-learn 1.8.0, LightGBM 4.6.0, joblib 1.5.2, PyYAML 6.0.3, and pyulog 1.2.4. TreeSHAP contributions were obtained from LightGBM's \texttt{pred\_contrib} interface. No supervised model was retrained or tuned for this revision. The separate replay residual and calibration variants are described in Section~\ref{sec:paired_replay_method} and the Supplementary Material; they do not alter the real-flight models. Model seeds were 0--4. The PX4 source-tree scan and controlled replay used commit \texttt{\seqsplit{82aa24adfca29321cfd1209e287eab6c2b16780e}}. The CATCH feasibility execution used the official core at commit \texttt{\seqsplit{3647c69be5eb56649b072596cf89098e689e20c3}}.

\subsection{Bootstrap and Split Settings}

Absolute real-flight confidence intervals used 1000 complete-flight cluster-bootstrap repetitions with random seed 20260825. Each bootstrap sample was evaluated for all five frozen model seeds and the replicate metric was their mean. ALFA used the same repetition count and seed with its 46 sequences as clusters; Uncategorized screening used its 1017 flights. Historical replay intervals used incomplete input runs and are excluded from the revised capability results. Corrected replay counts and their source-flight identities are provided descriptively in the Supplementary Material; no historical interval is reused. The fixed chronological split contained 152,340/32,138/34,059 train/validation/test windows; the 14-window purged split contained 133,353/8,536/17,966; leave-log-out contained 970/206/213 train/validation/test logs and 149,774/37,324/31,439 windows. All window models used length 96, stride 8, prediction horizon 12, 87 channels, and 1566 derived features.

\subsection{Conservative Source-Path Exclusion}

The confirmed firmware metadata indicated PX4FMU\_V2 with NuttX. The conservative sensitivity therefore excluded edges whose normalized source path contained markers for examples, templates, tests, POSIX, QURT, Bebop, Linux, Snapdragon, simulator, or replay code. The rule removed 35 of 180 edges: 14 for examples, 8 for POSIX, 7 for simulator/replay, 2 for QURT, and one each for Linux, Snapdragon, tests, and templates. The remaining 145 edges covered 36 modules and all 18 evaluated topics. The filtered table is a strict subset of the original table and passed the same evidence-conservation calculation. This path-based sensitivity is not equivalent to resolving CMake configuration, board manifests, conditional compilation, linking, or runtime activation for an actual PX4FMU\_V2 build.
