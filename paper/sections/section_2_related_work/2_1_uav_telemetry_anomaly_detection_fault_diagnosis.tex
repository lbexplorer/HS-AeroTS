\subsection{UAV Telemetry Anomaly Detection and Fault Diagnosis}

UAV telemetry anomaly detection and fault diagnosis combine system-specific flight knowledge with multivariate time-series analysis. Existing surveys organize this literature around model-based, signal-based, knowledge-based, and data-driven approaches, while noting the importance of validation with real flight data \cite{fourlas2021survey,puchalski2022uav,adaika2025fdd}. Flight logs contain coupled state estimates, estimator innovations, inertial measurements, actuator responses, power variables, and system-health indicators; an abnormal condition may therefore appear across several channels rather than as an isolated sensor excursion. Online detection has been studied for autonomous aerial vehicles, and datasets such as ALFA and UAV-SEAD provide real-flight annotations for fault and anomaly analysis \cite{keipour2019automatic,keipour2021alfa,kabaoglu2026uavsead}. In particular, UAV-SEAD organizes PX4 runtime anomalies into External Position, Global Position, Altitude, and Mechanical/Electrical domains, which directly supports the four-domain task considered in this paper. These studies and datasets provide the flight-domain foundation for HS-AeroTS, while their task definitions also motivate explicit separation between binary runtime screening and subsequent fault-domain diagnosis.

General multivariate time-series anomaly detection provides several complementary modeling paradigms for such data. Isolation Forest detects sparse deviations through random partitioning without explicitly modeling temporal order \cite{liu2008isolation}. Reconstruction and probabilistic sequence models learn normal temporal or inter-channel structure, as illustrated by MSCRED and OmniAnomaly \cite{zhang2019mscred,su2019omnianomaly}. Graph-based methods such as GDN learn dependencies among sensors, whereas TranAD and Anomaly Transformer use attention to represent longer temporal relationships \cite{deng2021gdn,tuli2022tranad,xu2022anomaly}. Recent methods further model cross-channel structure through frequency-domain patching in CATCH or a Granger-causality perspective in GCAD \cite{wu2025catch,liu2025gcad}. These approaches expand the modeling choices for multi-source flight data and generally produce anomaly scores or binary decisions. HS-AeroTS builds on this detection literature by treating the anomaly score as the entry point to a separate UAV-specific fault-domain task, and then connects the resulting evidence to an engineering architecture.

For real UAV telemetry, AeroTSBoost is the closest detector-level reference because it represents fixed-length flight windows with temporal-statistical descriptors and applies gradient-boosted trees to anomaly mining \cite{wei2026aerotsboost}. Its use of compact descriptors and LightGBM \cite{ke2017lightgbm} provides a reproducible option when the channel set is heterogeneous and the data are strongly imbalanced. The present study adopts an AeroTSBoost-compatible Stage 1 protocol for binary runtime anomaly detection, while extending the task in two directions. Stage 2 conditionally assigns anomalous windows to one of the four UAV-SEAD fault domains, and a Direct Five-Class model is retained as a non-cascaded comparator. This design makes the relation to prior detector work explicit: HS-AeroTS uses established telemetry representations for screening, while investigating how detection can be followed by domain diagnosis and traceable engineering evidence.

Evaluation choices are particularly consequential for imbalanced, overlapping telemetry windows. Accuracy and AUROC can remain high when normal windows dominate, whereas precision--recall analysis exposes the trade-off on the minority anomaly class \cite{davis2006relationship,saito2015precision}. Accordingly, AUPRC is emphasized for binary detection, while Macro-F1, Balanced Accuracy, and per-class Recall are used for fault-domain diagnosis so that minority domains cannot be hidden by aggregate accuracy. Time-series evaluation must also account for temporal range labels and partition dependence \cite{tatbul2018precision,wenig2022timeeval}. Randomly assigning overlapping windows can place nearly identical samples, or samples from the same flight log, in both training and test sets; benchmark analyses therefore emphasize the effect of evaluation design on reported robustness \cite{wu2023benchmarks}. The experiments in this study report fixed chronological results together with purged and leave-log-out protocols, and treat ALFA only as a zero-shot binary reference because its label space does not support direct four-domain transfer. These protocol choices provide the empirical basis for judging whether the proposed hierarchy remains informative beyond a single split.
