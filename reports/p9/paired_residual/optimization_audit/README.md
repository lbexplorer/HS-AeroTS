- 类型：现有实验的事后机制审计与改进设计，2026-09-06。

## 已证实的问题

主配置 Recall 12/12，但正常误报 11/12、故障 onset 前报警 10/12、无相应正常误报且无提前报警的故障检出仅 1/12。Top-1 6/12、Top-3/5 9/12、MRR 0.6369 不能单独证明可靠端到端诊断。

1. **相同输入不等于相同记录采样。** 正常目标与参考在共同源时间戳处的 `sensor_combined` 值完全一致；姿态角速度的相同值比例为 99.7846%–100%。但姿态共同时间戳仅占双方较短记录的 52.10%–98.39%，最大采样间隔可到 296.881 ms。全局时钟锚点偏差为零，只证明时钟映射正确，不能证明每个 topic 的采样覆盖一致。插值和窗口极值对这些差异敏感，是需要直接验证的传播路径。
2. **正常采样差异被极值特征和过小噪声尺度放大。** 多个正常误报由角速度的 range、max、diff_abs_max 驱动，所用特征噪声尺度恰落在 0.05 下限。正常姿态持续残差可到 125.07；EKF 正常的 estimator_status 持续残差可到 807.11，远超主阈值 26.47。
3. **检测和定位共用全局阈值，弱而有效的证据被清零。** INAV 三个故障的 vehicle_local_position 持续残差为 23.5057、26.1728、32.1082；前两者模块证据恰为零。它们的检测由姿态等其他 topic 触发，不能解释为成功发现高度冻结。
4. **部分好排名也缺少特异性。** EKF 直接被注入的 ekf2_innovations 持续残差约 19.8，低于阈值；两次该 topic 的最终证据为零，而正常 EKF 的 estimator_status 也产生很大残差。因此三个 EKF Top-1 不能全部归因于捕获了指定 innovation bias。
5. **仅提高全局阈值不可解决当前分数重叠。** 现有正常最大持续分数为 807.108；若用这样高的阈值消除这批正常误报，在既有分数下只有一个故障运行的最大持续分数还超过它。这是事后不可分性诊断，不是建议采用的校准值。
6. **独立性与注入效应仍有限。** 三个源航次均参与过原 P2 chronological 训练；Commander 的一个正常参考已有较多目标状态，既有注入效果检查仅 11/12 通过。不能删掉失败试验或选择有利航次。

## 优先改进顺序

### A. 先稳定配对预处理和残差特征

- 对全部 topic 采用统一、可观察的采样质量规则：记录覆盖率、间隔、数据年龄；对透传连续信号先在真实共同源时间点验证残差，再进行共同支持范围内的窗口统计。
- 重生成 topic 使用固定时间容差与有效覆盖要求，不能任意平移或动态对齐异常片段。离散状态使用保持/状态占比/转换次数，不将状态编号线性插值后的差异当作连续物理距离。
- 为 P9 分支提供稳健的位置、幅值和动态变化描述，如中位数/截尾均值、IQR、稳健差分；对极值和单点差分不再直接取 1566 个特征的最大值作为唯一门控。P1–P4 主结果保持原样。
- 先复用全部现有缓存进行描述子消融，再仅从现有 ULog 重新提取必要特征；无需重跑 P1–P9。
- 验证机制：正常同源对照残差与误报减少，同时保留 INAV 高度冻结和 EKF innovation 偏差的直接证据；不能只报告减少了报警。

### B. 正常数据校准 topic 尺度，分开检测与定位证据

- 从多条正常源航次的重复 replay 拟合每通道/每 topic 的自然波动，预处理拟合航次与阈值校准航次分开。
- topic 内稳健汇总并要求同 topic 持续异常，再使用正常完整航次的扫描统计量校准全局报警阈值，处理多 topic、多窗口搜索带来的误报。
- 定位证据采用相对各 topic 自己正常分布的超额偏离，避免继续用全局 26.47 一刀切清零所有模块证据。
- 可以把 bias、状态偏离与动态冻结建成统一的多分量残差，所有 topic 应用同一规则，不能依据 mutation 名称选用特征或权重。
- 单纯改为 topic 门控曾在开发消融中出现较高误报，不能当作已证实方案；须与 A 和正常校准共同验证。

### C. 多正常参考与初始化控制作为第二轮增强

- 对相同源日志生成多个独立健康 replay，建立参考中位数与正常分散程度；待测日志不参与其参考模型或阈值拟合。
- 少量开发航次先做三个健康参考加一个独立正常目标，判断多参考能否抑制估计器初始化/调度差异，再决定扩大运行量。
- 把可观察的估计器 readiness、日志覆盖和初始化状态作为一致的启动规则；不得固定等到真实注入时刻才启用检测。未就绪区间及其中的故障必须计为不可评估/漏检，报告可用率，不能静默排除。
- 若使用同航次健康参考，论文必须明确这是 matched-reference 诊断，其成本和前提不能省略。

### D. 检测稳定后再改进模块排序

- 由检测器自主确定报警事件，按事件汇总相对正常参考的新增证据，并输出证据不足/拒识状态。禁止使用真实 onset 切片；固定事件范围和延迟评价口径。
- 排名消融应比较：旧全程平均、事件证据、按正常噪声标准化证据；分别检查 INAV 真 topic 是否得到正证据、排名是否恢复。
- 静态 publisher 共用 topic 导致的同分应继续保守计分。若要解决 Land detector 与其他 publisher 的不可辨识性，必须新增可观测的运行时发布者信息或模块特有 telemetry，并对所有候选一致适用；不能用被注入模块打破并列。

## 可执行的验证路线

1. 将原三条开发航次与本次三条航次统一作为六航次开发池。先执行 A、A+B 两个有明确机制的消融，采用按源航次留一的开发评估；不得再称该池为确认测试。
2. 以固定低误报约束下的召回、故障特有检出率和 gated Top-3/MRR 为选择标准，同时报告数据可用率、提前报警和失败。不要用原始 Recall 或 MRR 单独择优。
3. 只有 A+B 显示正常与故障的分离确实改善时，再投入 C 的新增健康 replay。若正常仍高报警，暂停定位复杂化，继续查采样和初始化机制。
4. 最终只对 P9 训练/校准分支使用严格源航次隔离的标准化器与正常统计量。可复用已有 P11 训练集标准化器，但其训练源航次必须与新确认测试不重叠；原 P2/P3 模型若被保留作为对照，应单独披露其数据暴露。
5. 方法再次冻结后，另取足够多从未用于该方法设计、预处理拟合或阈值校准的 Normal 源航次，进行既有四类 mutation 与独立正常对照；全部试验计分。先做 20–30 条航次可明显强于三条的小样本验证，但零误报仍不能证明总体误报率低于 5%。若要在独立同分布航次假设下用零误报得到单侧 95% 上界低于 5%，至少需 59 条独立正常源航次；依据为 `(1-p)^n = 0.05`，不是窗口数或同航次条件数。

## 论文结论边界

当前证据支持“部分受控 mutation 的候选模块排序具有信号，但冻结检测器在新航次上的误报控制失败”，不足以支持可靠端到端诊断。下一轮最有依据的投入是 A+B；C 用于处理剩余运行差异；D 用于在真实检测事件上提高定位特异性。任何收益均需实测确认，不能保证得到预定论文指标。
